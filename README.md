# Entity ESP, NameTags, HitBox & Visuals Mod (Forge 1.16.5)

Полнофункциональный визуальный клиентский мод для Minecraft Forge 1.16.5 с современным меню настроек на **INSERT**.

---

## 🎮 Горячие клавиши (настраиваются в Настройки -> Управление)

| Клавиша | Функция | Описание |
| :---: | :--- | :--- |
| **INSERT** | **Меню настроек (ClickGUI)** | Открывает стильное интерактивное меню со всеми модулями и ползунками |
| **H** | **ESP On/Off** | Быстрое включение/выключение подсветки сквозь стены |
| **J** | **Hitbox Expander On/Off** | Быстрое включение/выключение расширения хитбоксов |
| **K** | **Размер Hitbox** | Быстрое изменение размера хитбокса (`+0.2`, `+0.4`, ... до `+2.0`) |
| **F3 + B** | **Дебаг-хитбоксы игры** | Отображает белую сетку хитбоксов (становится увеличенной при активном моде) |

---

## 🖥 Вкладки и функции меню на INSERT

### 1. 👁 Вкладка «ESP»:
- **ESP Master Switch**: Главный рубильник подсветки сквозь любые блоки и стены.
- **3D Box ESP**: 3D-рамка вокруг существ. **Важно:** Рамка использует исходные размеры моделей существ и **НЕ раздувается** при увеличении хитбоксов.
- **Tracer Lines**: Линии от вашего прицела к каждой сущности через стены.
- **Line Width**: Регулировка толщины линий (от `1.0px` до `5.0px`).
- **Max Distance**: Регулировка дистанции отображения (от `16m` до `128m`).

### 2. ⚔ Вкладка «HITBOX»:
- **Hitbox Expander**: Физическое расширение хитбокса сущностей для более лёгкой регистрации ударов и атак.
- **Hitbox Expansion (+0.0 ... +3.0 блоков)**: Кнопки `[-]` и `[+]` для точной регулировки размера увеличения.
- **Визуализация**: Увеличенный хитбокс виден при нажатии **F3 + B**.

### 3. 🏷 Вкладка «NAMETAGS»:
- **NameTags**: Плавающие плашки над головами существ, видимые сквозь стены.
- **Show Health**: Отображение текущего и максимального здоровья сущности (например: `(20/20 HP)`).
- **Show Distance**: Отображение точного расстояния в метрах (например: `[14m]`).

### 4. 🌟 Вкладка «VISUALS»:
- **Fullbright**: Режим ночного зрения (100% гамма — в пещерах и ночью светло как днём).
- **Фильтры целей**: Отдельные переключатели для игроков (`Players`), враждебных мобов (`Monsters`), животных (`Animals`) и предметов/транспорта (`Misc`).

---

## 🎨 Цветовая схема
- 🔵 **Синий / Голубой** — Игроки (`PlayerEntity`)
- 🔴 **Красный** — Враждебные мобы (`MonsterEntity`: зомби, скелеты, криперы)
- 🟢 **Зеленый** — Животные (`AnimalEntity`: коровы, овцы, свиньи)
- 🟡 **Желтый** — Жители и нейтральные существа (`MobEntity`)
- ⚪ **Серый** — Предметы, стрелы, вагонетки, лодки

---

## 📦 Установка мода
1. Файл **`espmod-1.0.0.jar`** находится прямо в корне проекта.
2. Скопируйте его в папку `.minecraft/mods/`.
3. Запустите игру с **Forge 1.16.5** и нажмите клавишу **INSERT** в игре для открытия меню.
